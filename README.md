# ETL vs ELT: Methodologies Comparison
 
A theoretical study of **ETL** (Extract, Transform, Load) and **ELT** (Extract, Load, Transform) approaches to data integration, developed for the **Information Systems II** course at the **Polytechnic Institute of Coimbra (ISEC)**.
 
The study compares classical and modern data integration approaches in the context of **Data Warehousing** and **Business Intelligence** systems.
 
## Objectives
 
- Understand the purpose and stages of ETL and ELT processes
- Compare traditional (on-premises) and cloud-based data integration methodologies
- Identify the main tools and technologies used in modern data pipelines
- Analyze the advantages, limitations, and performance considerations of each approach


## Topics Covered
 
- ETL and ELT concepts and workflows
- Data staging and transformation layers
- Data Warehouse architecture
- Overview of modern cloud ETL platforms (Azure Data Factory, AWS Glue, Google Dataflow)
- Comparison between on-premises and cloud integration models
- Best practices for scalability, automation, and data governance
